## 已稳定的基础能力

- 从本地游戏文件建立 VFS 索引，按逻辑路径定位、解密和读取单文件；
- 解析 `manifest.hgmmap`，按 manifest 资源索引直接读取对应 AssetBundle 内容；
- 按需导出 Unity 对象、TableCfg、已知 MemoryPack 配置、PCK/WEM 和媒体预览；
- 将 Prefab/PostModel 与 AvatarMesh 模型接入 ModelDocument、GLB、网页和 Blender；
- 将 Transform、Humanoid 和 Skeletal Morph 动画绑定到稳定模型节点；
- 按名称搜索、分页预览和多选导出动画；批量导出会保留成功项并逐项报告失败；
- 从 AudioDialog 建立对话语音逻辑目录，并从 Wwise HIRC 建立部分事件关系；
- 保存材质原始属性、纹理引用和 Shader 身份，并为 Blender 生成语义材质计划。

这些能力是后续研究的工具层，不代表模型、动画、Shader 或战斗规则已经完全恢复。

## 主线：战斗系统反推

近期目标不是立即实现一套新模拟器，而是建立可以复核的游戏运行时事实层：

1. 固定客户端版本、IL2CPP dump、VFS 索引和配置文件来源；
2. 建立 Skill、Buff、伤害、属性、资源、状态和条件类型地图；
3. 将配置字段与创建、释放、命中、结算和销毁调用链关联；
4. 优先恢复释放合法性、SP/终结技能量、冷却和连携窗口；
5. 再恢复伤害、失衡、附着、异常、Buff 叠层与持续时间；
6. 静态分析无法区分的分支再使用最小运行时探针验证；
7. 将确认规则整理成与 Endaxis 解耦的战斗语义 IR，再由适配器接入模拟器。

详细执行计划见[战斗系统反推计划](../research/combat-system-reversing-plan.md)。

## 支线：Shader 解包与反编译

当前 AnimeStudio 支线已能区分正式版内嵌 `SubShaderBlob` 与 CB3 外置
`SubShaderBinaryData`，并严格导出 LZ4 分块、程序容器、SubProgram 和 GPU 载荷。

尚未完成：

- 识别终末地类型 `7`、`25` 和 `33` 的完整语义；
- 去除 SPIR-V 和 D3D11 GPU 程序外层封装；
- 恢复关键字、Pass、平台程序和 Material 属性之间的稳定映射；
- 对可识别程序建立反射、反编译和材质语义 IR；
- 用当前客户端真实 Shader 替代第三方旧版本产物，复核角色光照与丝袜/面部公式。

支线不得修改战斗分析、模型动画绑定、网页服务和前端。跨线需求先通过文档和稳定中间格式交接。

## 阶段完成标准

战斗系统主线第一阶段完成时，应当能够从一个技能或 Buff 的稳定身份出发，给出：

- 配置来源和字段含义；
- 对应 IL2CPP 类型及关键方法；
- 从释放请求到资源扣除、命中和效果应用的调用链；
- 已确认条件、尚未确认分支和证据等级；
- 可复现的静态查询或运行时探针；
- 可供 Endaxis 使用、但不依赖 UI 文本的结构化规则。
